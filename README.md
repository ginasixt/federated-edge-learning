# Federated Edge Learning for Diabetes Screening

This repository contains the experimental code accompanying the bachelor thesis
**“Federated Edge Learning for Diabetes Screening: A Scalability Case Study.”**

The implementations and evaluation pipelines are organized in three
strategy-specific branches:

- [FedAvg](../../tree/FedAvg)
- [SCAFFOLD](../../tree/SCAFFOLD)
- [FedAdam](../../tree/FedAdam)

Each branch contains the corresponding training implementation, scalability
experiments, evaluation scripts, plotting code, and a strategy-specific README.
